# Task 1 - Personal Portfolio Website

## Project Description

This project is a full-stack personal portfolio website developed to showcase my education, skills, projects and contact information.

The project demonstrates frontend development, backend development, REST API integration and database connectivity.

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Tools
- VS Code
- Git
- GitHub

## Features

- Responsive personal portfolio
- Home section
- About section
- Skills section
- Education section
- Dynamic projects section
- Contact form
- REST API
- MongoDB database
- Project CRUD API
- Contact message storage
